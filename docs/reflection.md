# Project Reflection

This project gave me practical experience building and deploying a production-style customer support AI agent using Amazon Bedrock AgentCore and the Strands Agents SDK. I integrated AgentCore Gateway with two different backend targets: an API-based order-tracking service and a Lambda-based refund processor. I chose Gateway because it gives the agent a consistent MCP-based tool interface while keeping backend implementation details separate from the agent's reasoning logic. AgentCore Memory was also used to preserve semantic customer facts and user preferences across sessions.

A significant challenge occurred in the loyalty calculation. Code Interpreter produced the correct deterministic values, but the language model could occasionally reinterpret a returned number when generating its final response. I resolved this by using a Strands `AfterToolCallEvent` hook to capture the successful Code Interpreter result and return those calculated values in a customer-friendly format. I also encountered restricted IAM permissions in the AWS lab environment, so affected deployment operations were completed through the AWS Management Console while preserving the intended architecture.

A key production consideration for this agent is monitoring and reliability. Real customers could depend on the agent for order status and financial operations such as refunds, so repeated runtime or tool failures could directly affect customer experience and trust. To address this, I configured a CloudWatch `ERROR` metric filter and an alarm that triggers when more than five errors occur within five minutes. In a production environment, I would additionally route this alarm to an operational notification system and monitor Gateway and Lambda latency and failure rates. Security is also important because customer and order data are involved; production deployment should follow least-privilege IAM policies and avoid exposing credentials or sensitive customer information in application logs.

The completed agent was validated through deployed tests covering order tracking, refund processing, Knowledge Base retrieval, cross-session memory, deterministic loyalty calculations, and browser access.
